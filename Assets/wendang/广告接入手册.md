```
dirichlet_keys.json              ← 项目根目录，密钥配置（.gitignore 已忽略）
Assets/StreamingAssets/
  dirichlet_keys.json            ← 运行时读取（打包前从根目录复制）

  AdManager.cs                   ← 广告管理器
```

## 打包前步骤

1. 确认 `dirichlet_keys.json` 在项目根目录存在
2. 复制到 StreamingAssets：
   ```
   cp dirichlet_keys.json Assets/StreamingAssets/dirichlet_keys.json
   ```
3. Unity 中刷新（Assets → Refresh）
4. 正常打包

## 代码调用方式

### 激励视频（看广告得体力）

```csharp
// GameUIController / RewardPanel / EnergyInsufficientPanel 中已集成
if (AdManager.Instance != null)
{
    AdManager.Instance.ShowRewarded("energy", success =>
    {
        if (success)
        {
            // 发放奖励（+10 体力）
            EconomyManager.Instance?.AddEnergy(10);
        }
    });
}
```

### 插屏广告（可选，需先在后台创建广告位）

```csharp
AdManager.Instance.ShowInterstitial(() =>
{
    // 广告关闭后继续
});
```

## 运行模式

| 环境 | 行为 |
|------|------|
| Unity Editor | 自动模拟（`simulateAds=true`），不弹真实广告 |
| Android 真机（无配置） | 自动回退模拟，Console 输出警告 |
| Android 真机（有配置） | 调用 Dirichlet SDK 展示真实广告 |

## 调用链路

```
用户点击"看广告"
  → AdManager.ShowRewarded("energy", callback)
    → DirichletAdNative.ShowRewardVideoAutoAd(request, listener)
      → SDK 自动加载+展示激励视频
        → OnRewardVerify(args.IsVerified=true)  ← 广告平台验证通过
        → OnAdClose()                           ← 用户关闭广告
          → callback(true)                      ← 发放体力奖励
```

## 常见问题

### 广告加载失败
- 检查 `dirichlet_keys.json` 是否在 `Assets/StreamingAssets/` 中
- 检查 MediaKey 是否正确
- 检查手机网络连接
- 查看 Console 日志中的 `[AdManager]` 前缀信息

### 奖励未发放
- 必须 `OnRewardVerify` 中 `IsVerified=true` 才算有效观看
- 如果用户中途跳过广告，`OnAdClose` 时 `rewarded=false`，不发奖励

### 初始化失败
- 确认 MediaId 和 MediaKey 匹配（Dirichlet 后台「应用管理」中查看）
- 确认网络可达 Dirichlet 服务器

## Dirichlet 后台操作

1. 登录 https://ssp.dirichlet.cn
2. 「应用管理」→ 找到应用 → 获取 MediaKey
3. 「广告位管理」→ 创建激励视频广告位 → 获取 SpaceId
4. 将值填入 `dirichlet_keys.json`
